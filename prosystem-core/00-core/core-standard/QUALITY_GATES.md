# Quality Gates

A stable production template must pass all gates:

1. Structural validation.
2. Dependency and conflict validation.
3. Secret scan.
4. Security-baseline validation.
5. Automated tests.
6. Documentation completeness.
7. No unresolved critical placeholders.
8. Rollback or recovery instructions for state-changing deployments.
9. Ownership and version recorded.
10. Evidence-based completion; "looks correct" is not an acceptance criterion.
