# Naming Rules

- Template identifiers: lowercase kebab-case, for example `production-agent`.
- Agent IDs: uppercase prefix plus stable name, for example `AGENT-SEO`.
- Human titles: normal title case.
- Files that form public contracts use stable names and are not renamed casually.
- Secrets are referenced by environment-variable name only.
- No spaces in machine paths.
- No ambiguous suffixes such as `final`, `new`, `new2` or `latest`.
